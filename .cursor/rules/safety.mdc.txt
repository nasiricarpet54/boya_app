# ⛔️ قوانین مطلق و غیرقابل نقض (CRITICAL SAFETY RULES)

## 1. ممنوعیت حذف فایل و کد
- **هرگز** هیچ فایلی را حذف نکنید (`rm`, `del`, `Remove-Item`).
- **هرگز** محتوای یک فایل را به طور کامل پاک نکنید و از نو ننویسید، مگر اینکه صریحاً از شما خواسته شود.
- برای ویرایش، فقط از `replace` استفاده کنید و کدهای قبلی را حفظ کنید.
- هرگز کدهای موجود را "برای تمیزکاری" یا "بازنویسی" حذف نکنید. اگر کد مرده‌ای دیدید، فقط در مورد آن توضیح دهید و اجازه بگیرید[reference:0].

## 2. ممنوعیت اجرای دستورات مخرب
- **هرگز** دستوراتی مثل `git push --force`, `git reset --hard`, `git clean -fdx` را اجرا نکنید.
- قبل از اجرای هر دستور Terminal، **باید** از من تأیید بگیرید.
- هرگز فایل‌های مربوط به تنظیمات (`.env`, `tsconfig.json`, `package.json`, `.git`) را بدون اجازه تغییر ندهید[reference:1].

## 3. الزام به خروجی کامل کد
- هرگز از عبارات جایگزین مثل `// ... existing code ...` استفاده نکنید. همیشه کل فایل یا کل بخش ویرایش‌شده را به طور کامل بنویسید[reference:2].
